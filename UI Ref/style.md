# UI Style Guide

## Visual Direction

Create a clean AI workspace interface.

References:
- UI structure: Figure 1
- Color system: Figure 2
- Visual reference: Codex interface (Figure 3)

Core visual language:
- Professional productivity workspace
- Engineering tool interface
- Calm and precise
- High information density with clear hierarchy

The interface should feel like a serious creative and technical workspace, not a marketing website.

---

## Background & Surface

Default background:
- Neutral gray workspace background inspired by Codex.

Rules:
- Use gray as the main canvas.
- Create hierarchy through subtle surface differences.
- Avoid pure white full-page backgrounds.

Surface layers:
- Workspace background
- Content panels
- Floating utility areas

Use subtle contrast between layers instead of strong borders.

Avoid:
- Glassmorphism
- Blur effects
- Gradient backgrounds
- Strong shadows

---

## Typography

Primary font:
Urbanist

Use for:
- Headings
- Navigation
- Main interface content
- Important labels

Secondary font:
Inter

Use for:
- Small text
- Metadata
- File information
- Technical details
- Dense content

Typography rules:
- Clear hierarchy
- Medium and regular weights preferred
- Avoid excessive bold text
- Maintain comfortable line spacing

---

## Color System

Follow the provided color palette strictly.

Usage:
- Neutral gray dominates the interface.
- Brand colors are reserved for:
  - Primary actions
  - Important states
  - AI highlights
  - Key information

Rules:
- Keep most UI neutral.
- Avoid colorful decoration.
- Maintain strong readability.

---

## Layout System

Overall structure:
- Workspace-oriented layout
- Clear navigation area
- Main working area
- Supporting information panels

Layout principles:
- Strong alignment
- Consistent spacing
- Modular organization
- Large breathing space

Avoid:
- Dense dashboard layouts
- Random floating elements
- Excessive sections

---

## Cards & Containers

Use containers only when necessary.

Large sections:
- May use subtle background separation.
- May use minimal borders.

Small cards:
- Prefer no outline.
- Prefer flat grouping.
- Use spacing and background contrast instead.

Avoid:
- Every element inside a card
- Nested card structures
- Heavy container borders

---

## Buttons

Button style:
- Minimal
- Functional
- Flat

Rules:
- No strong outline.
- No pill-shaped buttons.
- No excessive rounding.
- Use subtle filled states.

Button hierarchy:
- Primary action: brand color background.
- Secondary action: neutral background.
- Tertiary action: text only.

---

## Panels & Navigation

Navigation:
- Compact
- Clean
- Tool-oriented

Panels:
- Use subtle gray layers.
- Keep boundaries lightweight.
- Prioritize content visibility.

---

## UI Density

Target feeling:
Codex / Linear style workspace.

Characteristics:
- Structured
- Efficient
- Quiet
- Professional

Information should feel organized rather than decorated.

---

## Icons

Use minimal icons.

Rules:
- Simple line icons.
- Consistent stroke.
- Only use when improving recognition.

Avoid decorative illustrations.

---

## Interaction States

Support:
- Default
- Hover
- Active
- Selected
- Disabled

Use:
- Background change
- Text contrast change
- Small color indication

Avoid:
- Large animations
- Strong glow effects

---

## Avoid List

Do not use:
- Glassmorphism
- Neon futuristic effects
- Heavy shadows
- Excessive rounded corners
- Excessive outlines
- Too many cards
- Dashboard-style widgets
- Decorative gradients

---

## Final Principle

Design the interface as:

"A quiet AI workspace where complex information becomes organized and actionable."

Prioritize:
1. Information hierarchy
2. Workflow efficiency
3. Content readability
4. Visual consistency
